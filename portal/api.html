服务台 API

接口位于同一服务。浏览器使用 HttpOnly 会话 Cookie；脚本可使用登录响应中的 Bearer Token。完整请求与响应定义见 OpenAPI JSON。

方法路径用途
POST/api/auth/login账号密码登录
GET/api/auth/me当前身份和 CSRF Token
POST/api/auth/logout注销并吊销 JWT
POST/api/chatAgent 问答；request_id 为幂等键
GET/api/conversations当前用户会话
GET/api/conversations/{id}读取本人会话
GET/api/actions操作与审批队列
POST/api/actions/{id}/decisionconfirm / approve / reject
GET/api/admin/audit管理员审计与完整性校验
GET/health/ready数据库与知识库就绪
GET/metricsPrometheus，需独立 Bearer Token

使用 Cookie 的写操作还需要 X-CSRF-Token 请求头，以及与 IT_ORIGIN 一致的 Origin。每个账号的受保护 API 限制为 60 次 / 分钟；登录另有限流。

敏感业务工具只生成待办。当前部署仅运行模拟业务适配器。权限申请不能由申请人自己批准。
